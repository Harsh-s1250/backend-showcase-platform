# Backend Showcase Platform

Turn your backend project into a live, interactive, shareable demo.

The platform connects to a GitHub repository, analyzes the project,
builds and deploys it in an isolated Docker environment, and provides
an appropriate interactive experience without requiring the developer
to build a separate frontend.

## Current Support

- Java / Spring Boot
- Maven
- PostgreSQL
- Docker
- REST APIs / OpenAPI
- Interactive API exploration

## Upcoming

- Automatic Spring Boot application UI
- Java console application browser terminal
- Automatic project-type detection
- Configuration/environment detection
